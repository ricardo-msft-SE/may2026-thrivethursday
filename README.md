# may2026-thrivethursday

Presentation workspace for a customer-facing Microsoft Foundry demo focused on first-time introduction, agent creation, and the May 2026 Foundry UI.

## Contents

- `index.html`: presenter landing page and section launcher
- `shared/`: common presentation theme and lightweight interaction logic
- `sections/`: self-contained section pages used during the talk
- `docs/`: speaker notes, runbook, and supporting material

## Getting started

Open `may2026-thrivethursday.code-workspace` in VS Code, then open `index.html` in a browser.

The presentation is designed to work directly from local files. If you later add pages that fetch JSON or other assets, run a lightweight local server instead.
