Section 03

Build a basic agent live without overexplaining setup

Target timing

6 to 8 minutes

Goal: make agent creation feel approachable while keeping momentum high.

This is the first major live moment. Keep the agent simple and use the interface to reinforce that creation is fast.

Build sequence

Three things to emphasize

Identity

Name the agent and define its role in plain language. Explain that instructions are where you describe what success looks like.

Behavior

Keep the initial instructions focused. For a first intro, do not try to model every edge case in the prompt.

Immediate test loop

Show that once the agent exists, the team can move directly into the Playground to test its behavior.

What not to do

Do not derail into model benchmarking, token settings, or prompt-engineering theory in this section.

Talking points

Speaker bullets

  • I’m starting with the simplest possible agent because the platform story matters more than prompt sophistication right now.
  • Instructions establish role, scope, and the style of response.
  • The real value appears when we add grounding and tools next.

Short script

Presenter-ready wording

This is the point where people often expect a long setup exercise. Instead, I want you to notice how quickly we can define the basics of an agent: who it is, what job it should do, and how we test it. I am intentionally keeping this first agent simple, because the next step is where it becomes useful: grounding it in knowledge and connecting it to tools.

Live switch

What to show in the UI

  • Open the Agents page and create or edit the demo agent.
  • Point out model selection only briefly. The audience does not need a model deep dive here.
  • Show the instructions pane and explain why concise instructions beat long paragraphs for a first demo.
  • Save, then pivot immediately toward tools and knowledge.
