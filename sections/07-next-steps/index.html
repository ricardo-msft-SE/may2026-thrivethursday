Section 07

Close the overview and hand off to the lab

Target timing

3 to 4 minutes

Goal: summarize the platform and make the hands-on exercise feel like the natural next step.

The audience should finish this section feeling that they have seen the platform map and are ready to try a simple grounded-agent workflow themselves.

Summary

What they should remember

Foundry covers the lifecycle

Creation, grounding, tools, safety, tracing, and evaluation belong to one operating model.

Agents are practical, not abstract

The audience has now seen how an agent can be defined, tested, and improved inside the same platform.

The exercise is intentionally basic

The hands-on portion should reinforce confidence, not maximize complexity.

AI Search grounding is the right next move

It gives a concrete and understandable scenario for first-time users: answer questions from files they control.

Talking points

Speaker bullets

  • You have seen the platform map and the main agent lifecycle.
  • The next step is to make it concrete with a simple grounded agent pattern.
  • We are moving into an exercise that uses files in AI Search so the grounding behavior is tangible.

Short script

Presenter-ready wording

At this point, you have seen the core Foundry story: create an agent, connect it to what matters, place controls around it, and inspect how it behaves. Rather than ending on architecture, I want to turn that into a simple exercise. The hands-on section uses a basic AI Search grounding scenario so you can see how quickly a useful first agent comes together.

Transition

What to do next

  • Close the overview pages and move into the exercise materials or live setup.
  • Explain that the exercise will stay intentionally narrow: answer questions grounded in files.
  • Use that scenario to reinforce the platform concepts they just saw.
